Quản lý dữ liệu & sao lưu

Xuất / nhập toàn bộ dữ liệu (CĐT, dự án, snapshot lịch sử, tài khoản người dùng).

Khôi phục dữ liệu mẫu

Đưa về dữ liệu mẫu mặc định (2 CĐT, 2 dự án, snapshot 8-9/2026).

Xuất dữ liệu (Backup JSON)

Tải file .json chứa toàn bộ dữ liệu và tài khoản người dùng.

Nhập dữ liệu từ file

Phục hồi từ file backup JSON đã lưu trước đó (có validate cấu trúc).

Cấu hình Firebase đã được nhúng sẵn trong file. Mọi máy mở file này sẽ tự động kết nối đồng bộ ngay khi đăng nhập — cán bộ KHÔNG cần dán cấu hình hay làm gì thêm. Ô bên dưới chỉ dùng nếu Admin muốn ghi đè sang project Firebase khác.
Đồng bộ đa máy (Firebase Firestore) — chỉ Admin cấu hình

Dán cấu hình Firebase (object JSON) để nhiều cán bộ trên các máy khác nhau dùng chung dữ liệu thời gian thực. Nếu để trống, phần mềm chạy offline (localStorage). Hướng dẫn: console.firebase.google.com → Tạo project → Firestore Database → Project settings → Config. Bắt buộc: tại Firestore → Rules, đặt allow read, write: if true; rồi nhấn Publish (dùng cho nội bộ). [Mới v4.3] Để không phải dán config trên từng máy, admin dán config 1 lần vào biến EMBEDDED_FIREBASE_CONFIG ngay trong file HTML (gần cuối phần code) — mọi máy mở file sẽ tự kết nối. Sau khi bật: mọi sửa đổi tự lưu cục bộ sau ~1 giây và tự đẩy lên cloud, máy khác nhận trong ~1–2 giây. Nếu mất mạng, dữ liệu vẫn lưu trong máy và tự đẩy lên khi có mạng lại.
